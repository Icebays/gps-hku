# Lifts & step-free routes

This page summarises the step-free routes and lifts that the HKU Estates Office publishes for the main campus. Always check the [official accessibility page](https://estates.hku.hk/campus-information/campus-accessibility/wheelchair-friendly-routes-hku-main-campus) for the latest details.

## Key lifts

| Lift | Stops |
|---|---|
| **MTR Exit C1 tower** | LG1 MTR · G/F Centennial Campus Central Podium |
| **MTR Exit A1/A2 tower** | C level MTR · G Pokfulam Road · footbridge to Upper University Street |
| **The Jockey Club Tower** | 1/F Centennial Garden · G/F Upper University Street · LG/F Lower University Street & Lee Shau Kee Lecture Centre |
| **Haking Wong Building** (two lifts, one near Union Restaurant) | 5/F Upper Univ. St. · 4/F Lower Univ. St. · G/F to Kadoorie Biological Sciences (Ramp A) and Pokfulam Road |
| **Between Library Old Wing & Hui Oi Chow** | 2/F Upper Univ. St. & Library 2/F entrance · 1/F Lower Univ. St. · G/F Sun Yat-sen Place, Knowles, K.K. Leung, East Gate |
| **Library New Wing** (outside Hui Pun Hing Lecture Hall) | G Sun Yat-sen Place / Library entrance · LG1 footbridge to Main Building |
| **Main Building** | LG1 to Library · 1/F Main Building & Loke Yew Hall |
| **T.T. Tsui Building** | 3/F to Swire, Tang Chi Ngong, K.K. Leung, Knowles · 1/F to Fung Ping Shan |
| **K.K. Leung Building** | G/F Knowles, Library, CYM Amenities (Ramp C) · LG2 Swire, Tang Chi Ngong, T.T. Tsui |
| **CYM Amenities Centre** | 5/F CYM Auditorium & Meng Wah G/F · 4/F CYM Canteen & Science Buildings · 2/F Shaw's Podium |
| **Wong Chuang Lai Wah Building** (Meng Wah) | 3/F footbridge to May Hall · 1/F Eliot Hall |

## Ramps

- **Ramp A**: G/F Haking Wong Building ↔ Kadoorie Biological Sciences Building
- **Ramp B**: James Hsioung Lee Science Building ↔ Run Run Shaw Building ↔ accessible car park
- **Ramp C**: G/F K.K. Leung Building ↔ G/F CYM Amenities Centre

## Not step-free

> [!WARNING]
> According to the Estates Office, these connections are **not** wheelchair accessible:
> - Main Library → G/F Main Building, Pao Siu Loong Building, Hung Hing Ying Building
> - James Hsioung Lee / Run Run Shaw Building → Graduate House, Robert Black College, University Lodge

If you need help getting around, the Estates Office lists the **24-hour Security Control Centre: 3917 2882**.
