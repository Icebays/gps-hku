# 步行路線

步行路線直接畫喺 3D 地圖上，每條都會顯示**距離**、**總爬升**同**預計步行時間**。時間大約以每小時 4.5 公里計，再加上每爬升 10 米多 1 分鐘，因為港大真係好斜。

## 查看路線

開啟 [3D 地圖](map)，按**路線**按鈕，揀一條就會喺地形上畫出嚟並飛過去。

> [!NOTE]
> 暫時未有已發佈嘅路線。路線由親身行過嘅貢獻者繪畫，所以會跟足真實嘅路、樓梯同升降機。想加一條，例如「港大站 → 總圖書館」或「百周年校園 → 鈕魯詩樓」？睇下面。

## 繪畫路線

1. 開啟地圖，按 **✎ 編輯**。
2. 按**繪畫路線**，然後順序點選沿路嘅位置：起點、每個轉角、每部升降機、終點。點會貼住你點中嘅地面或天台。
3. 按**複製路線 JSON**，然後喺 GitHub 貼入 `data/routes.json`，詳見[參與編輯](contribute)。

值得畫嘅路線：

- 港大站 C1 → 百周年校園 → 上大學街
- 港大站 A1 → 總圖書館
- 總圖書館 → 本部大樓（經圖書館新翼天橋）
- 梁銶琚樓 → 莊月明文娛中心 → 明華綜合大樓
