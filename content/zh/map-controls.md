# 地圖操作

| 動作 | 滑鼠 | 觸控 |
|---|---|---|
| 移動 | 左鍵拖動 | 單指拖動 |
| 旋轉／傾斜 | 右鍵拖動（或 Ctrl + 拖動） | 雙指扭動／拖動 |
| 縮放 | 滾輪 | 雙指開合；或者單手：輕按兩下唔放手，向上拉放大、向下拉縮小。輕按兩下即放大。 |
| 揀選大樓 | 點擊 | 輕按 |

## 按鈕

| 按鈕 | 功能 |
|---|---|
| 🧭 指南針 | 將視角轉返北向上，紅色尖端永遠指北。 |
| ↺ 重設 | 返回起始校園視角。 |
| ◇ 俯視／3D | 喺垂直俯視（好似平面圖）同傾斜 3D 之間切換。 |
| 🎯 定位 | 喺模型上顯示你嘅 GPS 位置。 |
| ⤴ 路線 | 列出步行路線，揀一條就會喺地圖上畫出嚟。 |
| ☰ 圖層 | 地圖樣式：經典（預設）或真實影像（航拍相同真實路面相片）；亦可顯示／隱藏地點類別。 |
| ✎ 編輯 | 貢獻者模式，用嚟標示大樓同繪畫路線，詳見[參與編輯](contribute)。 |

## 分享視角

網址會隨住你嘅操作更新。複製網址就可以分享某座大樓，例如 `#/zh/map?place=main-building`，或者某條路線，例如 `?route=...`。

> [!TIP]
> 第一次載入要下載大約 9 MB 嘅 3D 數據，之後瀏覽器會快取。
