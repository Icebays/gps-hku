# 地圖操作

| 動作 | 滑鼠 | 觸控 |
|---|---|---|
| 移動 | 左鍵拖動 | 單指拖動 |
| 旋轉／傾斜 | 右鍵拖動（或 Ctrl + 拖動） | 雙指扭動旋轉（以兩指中間為中心）；雙指一齊向上／向下拉就傾斜 |
| 縮放 | 滾輪 | 雙指開合（以兩指中間為中心）；或者單手：輕按兩下唔放手，向上拉放大、向下拉縮小。輕按兩下即放大。網頁本身唔會被放大。 |
| 揀選大樓 | 點擊 | 輕按 |

## 按鈕

| 按鈕 | 功能 |
|---|---|
| 🧭 指南針 | 將視角轉返北向上；再㩒一次就轉返望南。紅色尖端永遠指北。 |
| ↺ 重設 | 返回起始校園視角：同港大校園地圖一樣望南（校園後面嘅山喺上面）。 |
| ◇ 俯視／3D | 喺垂直俯視（好似平面圖）同傾斜 3D 之間切換。 |
| 🎯 定位 | 喺模型上顯示你嘅 GPS 位置。 |
| ⤴ 路線 | 列出步行路線，揀一條就會喺地圖上畫出嚟。 |
| 圖層（疊層圖示） | 地圖樣式：經典（預設）· 經典＋真實大樓（港大大樓用真實相片）· 衛星圖像（航拍相、真實路面及港大大樓、立體樹冠）。 |
| 篩選（滑桿圖示） | 顯示／隱藏地點類別。 |
| ✎ 編輯 | 貢獻者模式，用嚟標示大樓同繪畫路線，詳見[參與編輯](contribute)。 |

## 陽光、影同天氣

- **陽光同影**：太陽位置跟返而家喺港大嘅真實時間。大樓、天橋同樹會有柔和嘅影，日出日落光線會偏暖，夜晚光線平均冇影。多雲或者落雨時影會淡啲。衛星圖像本身已經有影，所以地面唔會再加。
- **天氣（左下角）**：顯示香港天文台而家嘅天氣同氣溫（香港公園站），生效中嘅警告會用圖標顯示：熱帶氣旋信號、暴雨（黃、紅、黑）、雷暴、酷熱／寒冷天氣、強烈季候風、火災危險、山泥傾瀉、新界北部水浸、霜凍同海嘯。㩒一下會顯示濕度、中西區雨量同警告全名。每 10 分鐘更新；連唔到天文台就唔會顯示。

## 分享視角

網址會隨住你嘅操作更新。複製網址就可以分享某座大樓，例如 `#/zh/map?place=main-building`，或者某條路線，例如 `?route=...`。

> [!TIP]
> 第一次載入要下載大約 9 MB 嘅 3D 數據，之後瀏覽器會快取。
