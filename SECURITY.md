# Security 安全

**English** · [繁體中文](#繁體中文)

## English

GPS-HKU is a static website: it has no accounts and no server of its own; it keeps only your settings (language,
theme, map style) in your own browser. Your location and
the camera (for the table-QR scanner) are used only in your browser and never sent anywhere. Online ordering and
payment happen on each restaurant's own order page, not on GPS-HKU.

### Reporting a vulnerability

Please **do not** report security problems in public issues or Discussions.

1. Use GitHub's private reporting: the repository's **Security** tab → **Report a vulnerability**.
2. If that is not available, open an issue titled "Security contact" **without any details**, and the maintainer will
   reply with a private way to reach them.

Include what the problem is, where (a link or file), how to reproduce it, and what an attacker could do with it.
You will get a reply as soon as possible; please give the maintainer reasonable time to fix it before telling anyone
else.

### In scope

- The website at https://icebays.github.io/gps-hku/ and the code in this repository.

### Not in scope

- The restaurants' ordering and payment sites, the Hong Kong Observatory, GitHub and other third-party services:
  report those to their owners.

## 繁體中文

GPS-HKU 是靜態網站：沒有帳戶、沒有自己的伺服器，只會在你自己的瀏覽器內保存設定（語言、主題、地圖樣式）。你的位置及相機（用於掃描枱號）只在你的瀏覽器內使用，從不傳送到任何地方。網上點餐及付款在各餐廳自己的點餐頁面進行，並非在 GPS-HKU。

### 回報安全漏洞

請**不要**在公開的 issue 或 Discussions 回報安全問題。

1. 使用 GitHub 的私密回報：本儲存庫的 **Security** 分頁 → **Report a vulnerability**。
2. 如未能使用，請開一個標題為「Security contact」的 issue，**不要包含任何細節**，維護者會回覆私下聯絡的方法。

請說明問題是甚麼、在哪裏（連結或檔案）、如何重現，以及攻擊者可藉此做甚麼。維護者會盡快回覆；在公開之前，請給予合理時間修正。

### 範圍內

- 網站 https://icebays.github.io/gps-hku/ 及本儲存庫內的程式碼。

### 範圍外

- 各餐廳的點餐及付款網站、香港天文台、GitHub 及其他第三方服務：請向其擁有者回報。
